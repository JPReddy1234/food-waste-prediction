# Food Waste Prediction System

## Project Overview
A machine learning project that predicts food waste in kilograms using historical data and kitchen operational features.

## Features
- Data preprocessing and exploratory data analysis
- Categorical feature encoding
- Comparison of regression models
- Model evaluation using MAE, RMSE, and R²
- Streamlit web interface for predictions

## Models Used
- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor

## Results
The Random Forest model achieved an R² score of 0.906 on the test set.

## Technologies
Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, Streamlit, Jupyter Notebook

## How to Run
Install dependencies:

    pip install -r requirements.txt

Start the application:

    python -m streamlit run app.py
